# ფანდური & გიტარა — საიტი (სატესტო ვერსია)

Next.js 15 (App Router) · ქართული / English · ტელეფონზე მორგებული.

## გვერდები

| მისამართი | რა არის |
|---|---|
| `/` | მთავარი: როგორ მუშაობს, წიგნები, უფასო გაკვეთილი, ჩემ შესახებ |
| `/book/panduri`, `/book/guitar` | წიგნის გვერდი / ყიდვა |
| `/activate` | შესვლა → წიგნის კოდის აქტივაცია |
| `/lesson/<book>/<N>` | გაკვეთილი — **ეს მისამართი იბეჭდება QR კოდად წიგნში** (მაგ. `/lesson/panduri/3`) |

## სატესტო ვერსიის შეზღუდვები

- შესვლა და აქტივაცია მხოლოდ ბრაუზერში (localStorage) ინახება — **დაცვა არ არის**. სატესტო კოდი: `DEMO-1234-5678`.
- გაკვეთილი 1 ყველასთვის ღიაა, დანარჩენი — აქტივაციის შემდეგ.
- ვიდეო, ფასები, არტისტის სახელი და ფოტოები — ჩანაცვლების ნიშნებია (`[...]`).
- გადახდა არ არის ჩართული.

შემდეგი ეტაპი: ნამდვილი ანგარიშები, ბაზა, ერთჯერადი აქტივაციის კოდები, დაცული ვიდეო (Bunny/Cloudflare Stream), BOG/TBC გადახდა.

## გაშვება ლოკალურად

```bash
npm install
npm run dev     # http://localhost:3000
```

## Vercel

vercel.com/new → Import ეს რეპოზიტორია → Deploy. პარამეტრების შეცვლა არ სჭირდება (Framework: Next.js).
